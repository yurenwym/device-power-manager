- `build.cmd` 构建成功，`/W4` 无编译警告。

- 31 项协议检查：短包、错误命令、离线、0% 合法值、百分比越界、键盘校验和及型号标识。

## 生命周期与界面

- 连续启动、重复启动打开已有实例、面板关闭、正常退出，共验证 3 个完整进程周期，退出码均 0。
- 实测正常退出耗时约 0.03–0.10 秒；退出后未残留控制窗口或面板。
- 在同一实例内打开/关闭面板 12 次：进程句柄数 336 → 336，GDI 对象数 28 → 26，没有观察到单调增长。
- 面板四行设备和底部控件已通过原生窗口捕获检查；真实百分比和状态均可见。
- 高 DPI 和新增设备的限高/滚动实现经过代码审查；未切换用户的系统显示缩放设置，未在多显示器/150% 实际桌面上验证。
- 测试期间保留已有启动快捷方式和用户所选状态，没有替用户修改自启选择。自启状态三次启动均保持已启用。

## 资源

以下来自面板反复打开后再关闭、只留下托盘的 35 秒采样：

| 指标 | 实测值 |
|---|---|
| GUI EXE | 360,960 字节，约 353 KiB（含电源图标与中文版本信息） |
| 私有提交内存 | 8,982,528 字节，约 8.6 MiB |
| 工作集 | 29,782,016 字节，约 28.4 MiB |
| 35 秒 CPU 时间增量 | 0 秒（系统采样分辨率内未增长） |
| 面板打开时私有内存 | 约 8.7 MiB |

私有内存和工作集是不同指标，不能只拿较小的一项代表全部内存占用。测试没有调用 EmptyWorkingSet 或其他强制清空工作集函数。

35 秒采样小于默认 60 秒刷新周期，主要代表消息循环空闲阶段；每次 HID 查询和刷新时会短暂使用 CPU。具体设备、输入法、系统主题和加载的系统组件也会影响工作集。

## 独立审查修复

1. I/O 超时后不再无限等待驱动取消；请求内存和句柄在完成前保持有效，隔离池限制为 16。
2. 重复型号按 Container ID 分开显示；读取失败清空当前百分比，避免串值或假新鲜数据。
3. 按显示器工作区限制窗口高度，并提供原生滚动条、鼠标滚轮与键盘焦点可见性处理。

审查复核未发现新的重要问题。未来设备的标准 HID 回退及其他固件变体仍需真机验证。
